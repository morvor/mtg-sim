# Oracle round trip

Generated by `cargo run --release -p mtg-tools -- roundtrip --write docs/ROUNDTRIP.md`.

Every fully supported card's compiled abilities are rendered back into Oracle-style text (`crates/mtg-engine/src/oracle/render/`, written independently of the parser) and compared with the card's Oracle text after the same normalization on both sides (reminder text, self-references, case, punctuation, number words, grammatical number). A card *passes* when every ability matches. `docs/roundtrip-passing.txt` lists the passing cards; they must stay passing (`roundtrip --check`, engine test `oracle_roundtrip`).

- Fully supported cards checked: **32076**
- Round-trip verified: **28455** (88.7%)
- Mismatches: **3469**
- With hand-written abilities (`crates/mtg-engine/src/cards/`), not checked: **152**

Sentence forms made uniform (`SENTENCE_FORMS`, `sentence_rewrites`):

- "Until end of turn, X." / "As long as C, X." / "At the beginning of the next end step, X." -> "X until end of turn." ...: Wording only (word order): a leading duration, condition or delayed time applies to the whole sentence wherever it's written.
- "Choose a creature type. [Instruction] ... the chosen type." -> "[Instruction] ... the creature type of your choice." (also colors, card types, basic land types; when the next instruction uses the choice and nothing later does): CR 608.2c: the same choice, made as the instruction that uses it is followed.
- "If C, you may put/cast Y. Otherwise, X." and "You may put/cast Y if C. Otherwise, X." -> "If C, you may put/cast Y. If you don't, X.": Treasure Chest ruling (2021-07-23): "The ‘otherwise’ in the last ability refers to whether or not you put it onto the battlefield, not whether or not it's an artifact card. You may put it into your hand even if it's an artifact card."; Fecund Greenshell (2024-07-26) and Aid from the Cowl (2017-02-09) rule the same of their "Otherwise": after an optional instruction it also covers not doing it (so for Bre of Clan Stoutarm too).
- "If C, Y. Otherwise, X." and "Y if C. Otherwise, X." -> "X. If C, Y instead." (not after "If you do", whose "Otherwise" is "If you don't"): Wording only (grammar): both state the same choice between two instructions.
- "X if C." -> "If C, X." (not "if able", "only if", "unless"): Wording only (word order): a trailing condition is the same condition.
- "You may pay P. If you don't, X." -> "X unless you pay P.": CR 118.12a: "[Do something] unless [a player does something else]" means the same thing as "[A player may do something else]. If [that player doesn't], [do something]."
- "N damage equal to V", "N life for each F", "+1/+1 for each F", "a card for each F", ... -> "X ..., where X is V": Wording only (number): both describe the same number (CR 107.3: X defined by the text).
- "+2/+2 for each F", "2 damage to P for each F", "two cards for each F" -> "X ..., where X is 2 times the number of F": Wording only (number): the same number, as above.
- "When C, at end of combat, X." -> "When C, X at end of combat." (a single instruction ending the ability): Wording only (word order): a delayed trigger's time applies to the instruction wherever it's written (CR 603.7).
- "Choose target T. [Instruction] it ..." -> "[Instruction] target T ..." (an instruction acting on it, not a condition): CR 601.2c, 602.2b: the target is chosen as the spell or ability is put on the stack either way.
- "up to X target T ..., where X is V" -> "up to V target T ...": CR 601.2c: when the text defines the number of targets, that number is determined as the spell is cast, from the text's value or from an X standing for it alike.
- "with mana value X or less ..., where X is V" -> "with mana value less than or equal to V ...": Wording only (number): the same comparison, with the number X stands for named in place (CR 107.3).

Ignored words (`IGNORED_WORDS`):

- `and`: Joins clauses and list items; instructions are followed in order (CR 608.2c) whether they're joined by "and", "then", or a period. A list of alternatives still says "or". (Dropping it also makes "all artifacts and creatures" and "all artifact creatures" compare alike, a known limit of this comparison; the union is checked in play, see the tests of the roundtrip items.)
- `then`: Wording only (sequencing): instructions are followed in the order written whether or not "then" says so (CR 608.2c).

Quantifiers that may be left out but never stand for one another (`OPTIONAL_QUANTIFIERS`):

- `each`: Universal quantification: "each", "all", or a bare plural.
- `a`: Indefinite article "a"/"an", or none with a plural.
