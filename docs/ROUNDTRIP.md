# Oracle round trip

Generated by `cargo run --release -p mtg-tools -- roundtrip --write docs/ROUNDTRIP.md`.

Every fully supported card's compiled abilities are rendered back into Oracle-style text (`crates/mtg-engine/src/oracle/render/`, written independently of the parser) and compared with the card's Oracle text after the same normalization on both sides (reminder text, self-references, case, punctuation, number words, grammatical number). A card *passes* when every ability matches. `docs/roundtrip-passing.txt` lists the passing cards; they must stay passing (`roundtrip --check`, engine test `oracle_roundtrip`).

- Fully supported cards checked: **22706**
- Round-trip verified: **18427** (81.2%)
- Mismatches: **4279**

## Allowed equivalences

Applied to both sides (`compare.rs`, `EQUIVALENCES`):

| Pattern | Replacement | Why |
|---|---|---|
| `\bwhenever\b` | `when` | "When" and "whenever" both introduce a trigger condition (CR 603.1); the choice of word has no rules meaning. |
| `\bis put into a graveyard from the battlefield\b` | `dies` | CR 700.4: "dies" means "is put into a graveyard from the battlefield". |
| `\bare put into a graveyard from the battlefield\b` | `die` | CR 700.4 (plural). |
| `\b(to\|into\|on top of\|on the bottom of\|onto) (your\|its owner's\|their owners'\|their owner's\|its owners') (hand\|library\|graveyard)` | `$1 owner's $3` | A card always goes to its owner's hand, library, or graveyard (CR 400.3); "your hand" on a card you own is its owner's hand. |
| `\bfrom (your\|a\|an\|their\|its owner's\|that player's\|target player's\|target opponent's\|an opponent's\|each\|all\|any) ((?:opponent's \|player's )?)(graveyards?\|hands?\|library\|libraries)\b` | `in $1 $2$3` | An object description says where the object is: "a creature card from your graveyard" and "a creature card in your graveyard" describe the same cards. |
| `\bfrom exile\b` | `in exile` | See "from your graveyard". |
| `\byou (draw\|discard\|mill\|scry\|surveil\|sacrifice\|create\|put\|return\|exile\|search\|reveal\|look\|shuffle\|tap\|untap\|destroy\|investigate\|proliferate\|seek\|conjure\|venture\|explore\|amass\|populate\|manifest\|cloak\|choose\|add\|counter\|attach\|transform\|gain\|lose\|get\|become\|take\|may\|cast\|pay\|play\|win\|skip)\b` | `$1` | An instruction without a subject is performed by the ability's controller (CR 608.2c, 113.8): "draw a card" and "you draw a card" mean the same. |
| `(sacrifices? [^.]*?) of (their\|his or her\|your) choice\b` | `$1` | The player who sacrifices chooses what to sacrifice (CR 701.21a); "of their choice" restates it. |
| `\bthat spell or ability\b` | `it` | Anaphora: "that spell or ability" refers back to the one already named. |
| `\bwould be dealt this turn (by\|to) ([^.]+?)(\.\|$)` | `would be dealt $1 $2 this turn$3` | Word order of the duration in a prevention effect. |
| `\bthat (creature\|permanent\|card\|spell\|land\|artifact\|enchantment\|planeswalker\|token\|aura\|equipment\|vehicle\|battle\|ability\|object\|source)s?'s\b` | `its` | Anaphora: "that creature's" and "its" both refer back to the object the text already named; the renderer always uses the pronoun. |
| `\b(that\|the) (creature\|permanent\|card\|spell\|land\|artifact\|enchantment\|planeswalker\|token\|aura\|equipment\|vehicle\|battle\|ability\|object\|source)\b` | `it` | Anaphora: "that creature" and "it" refer back to the object already named. |
| `\b(those\|the) (creatures\|permanents\|cards\|spells\|lands\|artifacts\|tokens\|objects)\b` | `them` | Anaphora (plural). |
| `\buntil end of turn\b` | `this turn` | "Until end of turn" and "this turn" effects both end in the cleanup step (CR 514.2). |
| `\. (it has\|they have\|it gains\|they gain) "` | ` with "` | A token created "with" an ability and one that "has" it (a following sentence) are the same token (CR 111.1). |
| `\breturn(s?)\b` | `put$1` | "Return" has no rules meaning of its own: it's a zone change like "put" (CR 400.6), described by its destination. |
| `\b(into\|onto)\b` | `to` | Prepositions of a destination zone ("into your hand", "onto the battlefield"). |
| `\bwith (x\|\d+\|an?\|one\|two\|three\|four\|five\|six\|seven\|eight\|nine\|ten) additional\b` | `with $1` | Counters an object enters with are put on it in addition to any others it would enter with (CR 614.1c, 122.6). |
| `\balso\b ` | `` | "Also" has no rules meaning. |
| `\beach player's (upkeep\|draw step\|end step)\b` | `each $1` | Each player has one upkeep (draw step, end step) per turn: "each upkeep" and "each player's upkeep" are the same steps (CR 501–503, 513). |
| `\bnumber of of\b` | `number of` | "For each of its colors" rewritten to the "where X is the number of" form. |
| `\bat the beginning of the end step\b` | `at the beginning of each end step` | Older wording: "the end step" in a trigger condition means every end step (CR 513.1a). |
| `\b(gets?) an additional ([+-])` | `$1 $2` | P/T modifications add up (CR 613.4c); "an additional +2/-2" is +2/-2. |
| `\b(is\|are\|was\|were\|do\|does\|has\|have)n't\b` | `$1 not` | Contraction. |
| `\ba player taps (an? [^.,]+?) for mana\b` | `$1 is tapped for mana` | Only a player can tap a permanent for mana (CR 106.12): "a player taps a land for mana" and "a land is tapped for mana" are the same event. |
| `\b(you\|they)'ve\b` | `$1` | "If you've gained life this turn" and "if you gained life this turn" ask the same thing. |
| `\b(draws?) an additional card\b` | `$1 a card` | A triggered draw is in addition to the normal draw anyway (CR 504.1). |
| `\bsupport (\d+\|x\|one\|two\|three\|four\|five\|six)\b` | `put a +1/+1 counter on each of up to $1 other target creatures` | CR 701.41a: "Support N" on a permanent means "Put a +1/+1 counter on each of up to N other target creatures." |
| `(^\|\. )([^.]+?) can't block (~\|it)(\.\|$)` | `$1~ can't be blocked by $2$4` | "Creatures with power less than ~'s power can't block it" and "~ can't be blocked by creatures with power less than its power" are the same blocking restriction (CR 509.1b). |
| `\bthe exiled (card\|creature\|permanent)s\b` | `the exiled $1` | Grammatical number. |
| `\bremove any number of (\S+) counters\b` | `remove x $1 counters` | A cost of X counters is paid with any number of them (CR 107.3). |
| `\band/or\b` | `and` | In a list of object kinds, "artifacts and/or enchantments" and "artifacts and enchantments" both mean objects that are either. |
| `(^\|[^~\w])(it\|that\|there\|what\|he\|she)'s\b` | `$1$2 is` | Contraction. |
| `\b(adds?) an additional\b` | `$1` | A triggered mana ability's mana is added in addition to the mana the permanent produced (CR 605.1b, 106.12a); "additional" restates it. |
| `\bthem\b` | `it` | Pronoun number (grammatical number is ignored). |
| `\bthey\b` | `them` | Pronoun case: "they"/"them" refer to the same objects. |
| `\btheir\b` | `its` | Pronoun number: "their" and "its" (grammatical number is ignored, see singularization). |

Ignored words (`IGNORED_WORDS`):

- `and`: Joins clauses and list items; instructions are followed in order (CR 608.2c) whether they're joined by "and", "then", or a period. A list of alternatives still says "or".
- `then`: Sequencing word: CR 608.2c, instructions are followed in the order written.
- `each`: Universal quantification is written "each X", "all Xs", or a bare plural ("creatures you control get +1/+1"); all mean every object that matches.
- `all`: See "each".
- `a`: Indefinite article: "a"/"an" vs none ("put a +1/+1 counter" vs "put +1/+1 counters"); counts are always explicit (one, two, X).
