# roundtrip-parser-bugs-1: Oracle round-trip follow-up, part 1 (parser bugs and non-gap clusters)

Background: `mtg-tools roundtrip` renders every fully supported card's compiled abilities (AST) back to Oracle-style English (crates/mtg-engine/src/oracle/render/, written independently of the parser) and compares with the Oracle text (render/compare.rs). docs/ROUNDTRIP.md lists the mismatches in clusters; docs/agents/items/oracle-roundtrip.md is the original brief. GOAL: drive round-trip mismatches toward zero so every supported card is verified.

SCOPE of this item: every cluster in the "Mismatch clusters" table of docs/ROUNDTRIP.md with 10 or more cards that is NOT a "gap: ..." cluster (those go to a separate renderer-gaps item), i.e. "this ability costs {1} less", "was" vs "is", "it" vs "~", "a"/"of"/∅ vs "among", "as though its power were", "an instant or sorcery spell" vs "up to one nonland instant", "each of", "it's still a land" / "in addition to its other types", "turn if able" vs "combat if able this turn", "any number of" vs "up to 4", "exile … from the top" vs "reveal … from the top" (Chaos Wand, Wanda's Vision), "from anywhere other than your" vs "that is not a permanent", "it" vs "that player"/"you", "named" vs "with the same name as", "the upkeep of enchanted creature's controller", "to ~" missing. Regenerate the report first (`cargo run --release -q -p mtg-tools -- roundtrip --write docs/ROUNDTRIP.md`; origin has moved) and use the current list. Also take the two known likely parser bugs: Ricochet Trap ("an opponent" rendered as "each opponent") and Earthbender Ascension's "It gains trample" pointing at the wrong object.

For each cluster, triage every card (use `roundtrip --card NAME --ast`): (a) PARSER BUG — the AST doesn't mean what the text says: fix the parser (generally, not per card) or make the text unsupported; EVERY parser bug fixed needs an in-game test (TestGame, real card) showing the corrected behavior, which fails on the old code; (b) RENDERER GAP — fix the renderer, keeping it independent of the parser (never reuse the parser's phrase tables or print stored source text); (c) TRUE EQUIVALENCE under the CR — add to the one EQUIVALENCES list with a CR-cited justification, only if the two wordings genuinely mean the same; never add an equivalence or loosen the comparison to hide a real difference. Clusters like "any number of" vs "up to N", "exile vs reveal", "named vs same name", "turn vs combat if able" are suspected real misreads — check carefully.

When done, regenerate docs/ROUNDTRIP.md and docs/roundtrip-passing.txt with the tool (`--write`), and add this brief as docs/agents/items/roundtrip-parser-bugs-1.md. `roundtrip --check` must pass (no previously passing card may start failing unless it was wrongly passing — justify each).
