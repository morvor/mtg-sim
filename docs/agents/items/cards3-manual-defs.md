# cards3-manual-defs: Hand-written card definitions III: one-off abilities with no shared construct — 8 texts / 7 cards (3 unlocked alone)

SCOPE: 8 unsupported ability texts on paper cards, blocking 7 paper cards; 3 of those become fully supported when this item alone is done (the other 4 also have a text owned by another item, listed under ALSO BLOCKED BY). After cards-manual-defs-2 landed, the 4 one-off texts it left unsupported were added (see ADDED AFTER CARDS-MANUAL-DEFS-2 LANDED). The user deferred the two dexterity cards on Oct 21 (Chaos Orb, Falling Star; docs/DEFERRED.md, "Dexterity cards"), so their 2 texts moved to round3/deferred.tsv. All 8 texts were in an earlier card item and are still unsupported after it landed (cards-manual-defs-2 4, cards-game-rules 2, cards-mana 2). The review moved Verrak, Warped Sengir to cards3-triggers-durations (family `trigger-modifiers`): "if life was paid to activate it" is the same construct as Ashnod the Uncaring's "if one or more permanents were sacrificed to activate it" and Way of the Mind Sculptor's "if you removed two or more loyalty counters to activate it" (the costs paid for the activation that triggered the ability), so it must be compiled. No text has a second failing piece found by the plan's probes. The full list ships as items/cards3-manual-defs.texts.tsv (columns: cards blocked, normalized text, example card, piece kind, failing piece, family, previous item, note). Normalized text = reminder text removed, the card's own name as ~, numbers as N.

GOAL: Write hand-written definitions (src/cards/, `ManualAbility`, a test per card in tests/cards/m_<card>.rs, `mtg-tools manual-check`) for the texts below, which the round-3 classification found to have a construct no other in-scope paper card shares (checked by searching all paper cards' Oracle text for the construct, see each reason). COMMON RULES FOR CARD ITEMS (round 3):
- These texts are the long tail: most were in a round-1 or round-2 item (column previous_item) and are still unsupported after it landed. Before starting a family, read that item's brief and its commits (`git log --grep '^<item>:'`) for the reason it stopped; re-probe the text (`docs/agents/round3/probe.py --card "<Name>" --text "<edited text>"` compiles edited texts as variants of the real card, with its other paragraphs and types, in one run of the release mtg-tools; `mtg-tools unsupported --text "<text>" --type "<type line>" [--ast]` compiles one bare text) to find the exact failing words: the failing_piece column is the sentence (or cost, trigger, mode, table row) that fails, not always the smallest failing phrase. Column note "then also: ..." is the next piece that still failed with the first one replaced by a filler (sometimes only a referent to the replaced words).
- Generalize. Implement each construct as grammar (subject / verb / object phrase / qualifiers composed from phrases.rs, the value and condition parsers and the Builder's referent tracking), never one pattern per card wording; a fix should also cover wordings that aren't in the list. Unit-test the grammar on several real wordings.
- Faithfulness first. The parser must not accept text the engine doesn't implement exactly (the Oracle round-trip check audits every compiled card). For each family add TestGame tests with real cards that assert the in-game outcome (crates/mtg-engine/tests/cards/ or tests/cr/, citing cr!() for rules exercised and ruling!() for Scryfall rulings exercised).
- No round-2 item is in flight any more (round3/inflight.tsv is empty: cards2-triggers-delayed, cards2-copies-tokens-counters and cards-manual-defs-2 all landed while round 3 was planned, and their still-unsupported texts are planned in cards3 items). Cards with a text here and a text in another cards3 item are listed under ALSO BLOCKED BY: do your text; the card becomes supported when both land.
- One-offs. The hand-written mechanism exists (src/cards/, `ManualAbility`, `mtg-tools manual-check`; policy in src/cards/mod.rs). If a text here turns out to be a genuine one-off (no other in-scope paper card shares the construct: search the card data before deciding), don't force a pattern: list it in your report for a manual-definitions item. Never hand-write a construct that two or more cards share.
- Shared core files (oracle/effects.rs, phrases.rs, statics.rs, triggers.rs, costs.rs, ability.rs, eval.rs, resolve.rs) are edited by several items in parallel: keep edits there small (hooks, new enum variants handled everywhere), put grammar in this item's own pattern files, and merge origin often.
- Build hygiene (CLAUDE.md): `export CARGO_BUILD_JOBS=2`, one cargo build at a time per worktree, no second checkout for before/after numbers.
- Measure before and after: `cargo run --release -q -p mtg-tools -- card-coverage`, the baseline filters (`cargo run --release -q -p mtg-tools -- unsupported --paper --limit 500 --filter "<s>"`) and `mtg-tools unsupported --card "<Name>"` for the listed cards. Report per family: texts fixed, texts remaining (each with a reason). Run `cargo run --release -p mtg-sim -- --random-decks --games 300` before finishing to catch panics in newly supported cards.
- DONE when about 90% or more of this item's texts compile with faithful, tested behaviour (at least one TestGame test per family with a real card) and every remaining text is listed with a reason (engine gap, belongs to item X, manual candidate, proposed deferral).

REVIEW (Oct 21): Jeweled Amulet is not a one-off. Ice Cauldron ("note the type and amount of mana spent to pay this activation cost" / "Add this artifact's last noted type and amount of mana") is legal in Legacy, Vintage and Commander although its Scryfall oracle record lists only MTGO (an MTGO-only reprint; see docs/agents/round4/paper-scope-gap.tsv), so noting the mana spent on an activation must be compiled (compile-first). The hand-written draft (card, 4 tests, the `ManaProduction::Custom` / `custom_mana_types` hook and the `jeweled-amulet-several-types` interpretation) was removed and saved as `cards3-manual-defs.jeweled-amulet/draft.patch` for the item that compiles the construct. The other one-off claims were rechecked by legality: Aeon Engine's only other reversers (Topsy Turvy, Time Distortion, Temple of Atropos) are legal in no format; Keen-Eared Sentry, Suffocation and Unbound Flourishing have no legal card sharing the construct.
