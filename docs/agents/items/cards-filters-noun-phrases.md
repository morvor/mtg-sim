# cards-filters-noun-phrases: Object-phrase grammar II: noun-phrase core (disjunctions with distinct adjectives, color/quality predicates, elliptical "and a [counter] on [Y]" clauses) — 127 texts / 126 cards (108 unlocked alone)

SCOPE: 127 unsupported ability texts (127 on paper cards) blocking 126 paper cards; 108 of those become fully supported when this item alone is done (the others also have a text owned by another item). The full list, with the failing piece found by compiler probes, ships as items/cards-filters-noun-phrases.texts.tsv (columns: cards blocked, normalized text, example card, piece kind, failing piece). Normalized text = reminder text removed, the card's own name as ~, numbers as N.

GOAL: Fix the core noun-phrase and coordination grammar in phrases.rs: disjunctions whose members carry their own adjectives ("target land or nonblack creature", "noncreature artifact or noncreature enchantment", "multicolored creature or multicolored enchantment", "target artifact or tapped creature", "target permanent you own or control"), predicates ("that's one or more colors", "that isn't all colors", "with mana value of the chosen quality", "with flash or haste", "with islandwalk", "that's attacking you or a planeswalker you control", "tokens created with it"), and elliptical coordination where the verb is shared ("put a +1/+1 counter on that creature and a plan counter on ~", "Put two +1/+1 counters on target creature and two +1/+1 counters on another target creature", "~ deals 2 damage to target player and 1 damage to each creature that player controls").

PHRASE FAMILIES (texts in family; representative failing pieces and cards):
- elliptical second clause ("Put a +1/+1 counter on X and a plan counter on Y", "N damage to A and N damage to B"): 25. e.g. "Put a +N/+N counter on each creature you control and a loyalty counter on each other planeswalker you control." [Ajani Steadfast]; "put a +N/+N counter on it and a +N/+N counter on ~." [Sumala Sentry]; "~ deals N damage to any target and N damage to any target of an opponent's choice." [Cuombajj Witches]
- disjunctions with distinct adjectives ("target land or nonblack creature", "noncreature artifact or noncreature enchantment", "multicolored creature or multicolored enchantment"): 16. e.g. "Destroy all lands or all creatures." [Catastrophe]; "Destroy target land or nonblack creature." [Stream of Acid]; "Return target spell or nonland permanent an opponent controls to its owner's hand." [Press the Enemy]
- color/quality predicates ("that's one or more colors", "that isn't all colors", "with mana value of the chosen quality"): 13. e.g. "Destroy each creature that isn't all colors." [Iridian Maelstrom]; "exile target permanent that's one or more colors." [Devourer of Destiny]; "exile up to one target permanent that's one or more colors." [Ugin, Eye of the Storms]
- keyword / ability predicates ("with flash or haste", "with islandwalk"): 2. e.g. "Destroy target creature with islandwalk." [Merfolk Assassin]; "put a +N/+N counter on each creature you control with flash or haste." [Sonic the Hedgehog]
- combat-relation predicates ("that's attacking you or a planeswalker you control", "blocking equipped creature"): 18. e.g. "Exile ~ and target creature without flying that's attacking you." [Hunting Kavu]; "Untap target nonattacking creature." [Alarum]; "Creatures can't attack planeswalkers you control unless their controller pays {N} for each creature they control that's attacking a planeswalker you control." [Onakke Oathkeeper]
- ownership/control combos ("you own or control", "created with it"): 6. e.g. "Exile target permanent you own or control." [Telim'Tor's Edict]; "Return each nonland permanent that's not historic to its owner's hand." [Desynchronization]; "exile all tokens created with it at the beginning of the next end step." [Arcane Artisan]
- other (mixed; read the texts): 47. e.g. "Gain control of all commanders." [Tevesh Szat, Doom of Fools]; "Destroy all Auras and Equipment." [Pure // Simple]; "Exile all creatures and Spacecraft." [Beyond the Quiet]

APPROACH: 1. Parse a noun phrase as a disjunction/conjunction of complete noun phrases, each with its own determiner-less adjective list and head noun, with distributive adjectives only when the text distributes them ("nonland, nontoken permanent"). Keep the rule in the existing comment in effects.rs (an alternative of several words after "or" isn't read as sharing the first one's adjectives) but now parse it instead of refusing.
2. Ellipsis (gapping): when a clause "VERB A PREP B and C PREP D" fails, retry as two clauses with the verb copied ("put [A] on [B]" + "put [C] on [D]"; "deal [N] damage to [B]" + "deal [M] damage to [D]"). Implement once in `effects::parse_clause` as a fallback split, not per verb.
3. Quality predicates as adjectives/suffixes: color counts ("one or more colors", "exactly two colors", "all colors"), keyword possession (`Filter::HasKeyword` exists), combat relations.

PARSER FILES INVOLVED: oracle/phrases.rs (adjective, head_noun, parse_object_phrase, parse_with_suffix), oracle/effects.rs (parse_clause split), oracle/keywords.rs (quality_phrase)

FILES THIS ITEM OWNS: oracle/phrases.rs core grammar (this item is the owner of phrases.rs internals; cards-filters-relational adds only a suffix hook); new oracle/patterns/noun_phrase_ellipsis.rs

ENGINE CAPABILITIES: None expected (Filter::Or/And/Not, Multicolored, ExactColors, HasKeyword exist). Risk is regressions: phrases.rs is used by every pattern — run the full test suite and compare `card-coverage` before/after to make sure no supported card changes meaning (the oracle round-trip check, when available, is the safety net).

BASELINE (`cargo run --release -q -p mtg-tools -- unsupported --limit 500 --filter "<s>"`; counts include other items' texts and digital-only cards): `or nonblack` → 2 texts / 2 cards; `noncreature artifact or noncreature` → 3 texts / 3 cards; `one or more colors` → 11 texts / 11 cards; `counter on that creature and` → 5 texts / 5 cards; `damage to target player and` → 4 texts / 4 cards

COMMON RULES FOR CARD ITEMS:
- Generalize. Implement each construct as grammar (subject / verb / object phrase / qualifiers composed from phrases.rs, the value and condition parsers and the Builder's referent tracking), never one pattern per card wording; a fix should also cover wordings that aren't in the list. Unit-test the grammar on several real wordings.
- Faithfulness first. The parser must not accept text the engine doesn't implement exactly (an Oracle round-trip check audits every compiled card). For each family add TestGame tests with real cards that assert the in-game outcome (crates/mtg-engine/tests/cards/ or tests/cr/, citing cr!() for rules exercised and ruling!() for Scryfall rulings exercised).
- A text can contain a second failing construct owned by another item. Fix it when it is small; otherwise leave it and list it under remaining gaps with the owning item.
- One-offs. If a text's construct is genuinely unique (no other card shares it) and compiling it would be hacky, don't force it: once cards-manual-defs has landed, give it a hand-written definition in src/cards/ with a test; before that, list it as a manual candidate.
- Shared core files (oracle/effects.rs, phrases.rs, statics.rs, triggers.rs, costs.rs, ability.rs, eval.rs, resolve.rs) are edited by several items in parallel: keep edits there small (hooks, new enum variants handled everywhere), put grammar in this item's own pattern files, and merge origin often.
- Measure before and after: `cargo run --release -q -p mtg-tools -- card-coverage` and the baseline filters above. Report per family: texts fixed, texts remaining (each with a reason). Run `cargo run --release -p mtg-sim -- --random-decks --games 300` before finishing to catch panics in newly supported cards.
- DONE when about 90% or more of this item's texts compile with faithful, tested behaviour and every remaining text is listed with a reason (engine gap, belongs to item X, manual candidate).
