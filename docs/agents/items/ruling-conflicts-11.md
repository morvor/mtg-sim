# ruling-conflicts-11: Twinning Staff with "for each ..., copy that spell" (2N or N+1 copies?)

Run at effort max, with an independent investigator subagent and a separate adversarial skeptic subagent, as in ruling-conflicts-1. Judgment calls go in the register; conflicts go to the user with every source quoted verbatim with dates.

**Raised by:** small-fixes-1 (landed 1c9bf67). Unregistered behavior, predates that item.

**The question.** Twinning Staff (Oracle): "If you would copy a spell one or more times, instead copy it that many times plus an additional time. You may choose new targets for the additional copy." The engine adds one copy per copy instruction. So "for each [object], copy that spell" (Feather, Radiant Arbiter; Zevlor, Elturel Exile; and others) gets 2N copies with Twinning Staff, while "copy it for each [object]" / "copy it N times" (Reverberate-style "copy it X times", Bonus Round? no; Twinning Staff's own rulings, Thousand-Year Storm, Ral's emblem? check) gets N+1. Is a "for each X, copy that spell" one copy event of N copies (N+1 with the Staff) or N separate events (2N)?

**Survey.** Twinning Staff's rulings (all, with dates); rulings of other "copy ... one or more times / that many times plus" replacements (e.g. Double Vision? Mirrorwing? search data for "copy it that many times plus" and "one or more times"); rulings on Feather, Zevlor, Kalamax, Lier? and other "for each ..., copy" cards; CR 707.10 (and 707.10c/d), 614.1, 616 (one replacement event), 609.3, 608.2c/608.2f (actions on multiple objects processed simultaneously vs one at a time). Collect any ruling that counts copies under a "for each" wording.

**Outcome.**
- **A source decides it:** make the engine follow it generally (one rule for how copy instructions group into events), with tests citing cr!/ruling!, and a decided register entry.
- **Nothing decides it:** keep the best-supported reading, add a PROVISIONAL register entry with every source quoted verbatim with dates and the alternative, and pin it with interp!.
- Follow worker.md's one-item-per-session rule and notify the coordinator when it lands.

## STATUS

Investigated (Nov 19) by an independent investigator, then reviewed by an adversarial skeptic, who upheld the conclusion and the engine change and added evidence ("Skeptic's review", at the end). **Conclusion D (no source decides it), with the evidence weighted to N + 1.** The engine gave 2N, the less-supported reading; it now gives N + 1, registered as the provisional interpretation `copy-for-each-one-copy-event` (docs/interpretations/copy.md) for the user.

**The sources don't settle it.**
- **What no source says:** no ruling, release note or rule names Twinning Staff (or any copy-count replacement) with a "for each ..., copy that spell" instruction. Twinning Staff's rulings (2020-04-17) predate Zevlor (2022), Feather (2024) and CR 608.2f's "processed simultaneously" sentence (CR effective 2020-11-20).
- **For N + 1 (one copy event):** CR 608.2f performs a "for each" action for all the objects at once unless it can't be; Twinning Staff's own text defines its event as copying a spell "one or more times" (700.1), which it modifies once (614.5), and its ruling has "the additional copy" go "in between the original copies" when "a spell is being copied more than once"; Feather's ruling describes its "for each" copies as Zada's describes its CR 707.10d copies, which the engine (and the Staff's ruling, read as covering them) gives one additional copy; rulings on other "for each" instructions call them "a single event" (Culmination of Studies) or done "all at the same time" (Tempting Contract); additive "one or more" replacements apply once to an instruction that does something several times (Heron of Hope, Angel of Vitality, Pest Rescuer, Quantum Riddler), and to what several sources do at once (Vizier of Remedies).
- **For 2N (one event per pass):** the tempting offer rulings (2013, reused 2024) have the effect for "For each opponent who does" "happen again for you a number of times", and the 2013 release notes call it letting opponents share the effect "if they allow you to repeat it"; the cards' per-pass wording ("copy that spell. The copy targets that creature."); Winding Constrictor's ruling counts instructions (but a "for each" instruction is one).
- **No ruling contradicts another or the CR** on this question, so no entry is added to docs/RULING_DISCREPANCIES.md for it (the survey found one unrelated template copy, Siege of Towers', now listed under "Not yet investigated" there; see "Noticed").
- **Recommendation:** N + 1 (see "For the user").

**Ruled out.**
- **Not A:** there is no conflict between sources to reconcile; the question is a gap. The reading N + 1 makes every source fit, but so, more awkwardly, does 2N, since none of them speaks of a "for each ..., copy" instruction's event.
- **Not B:** no dated rules change bears on it. 608.2f's sentence (2020-11-20) came after the tempting offer rulings (2013) and Twinning Staff's (2020-04-17), and it supports N + 1; the 2013 wording was reused, but for a comma, for Tempt with Bunnies (2024-07-26).
- **Not C:** no ruling decides it. Twinning Staff's "If a spell is being copied more than once" ruling fits Feather only if Feather's copies are one copying, which is the question.

**Engine: changed (from 2N to N + 1).**
- **Before** (confirmed with a scratch test, Nov 19): with one Twinning Staff, Feather with two creatures chosen made 4 copies and Zevlor with two other opponents made 4, while Zada with two other creatures made 3 (`copy_rules::copy_for_each_target`, CR 707.10d) and "copy it twice" made 3 (`Effect::CopySpell { count }`). Feather compiles to `ForEach { CopySpellRetargeted { target: Some(each) } }`, and each pass called `copy::additional_copies`; Zevlor compiles to `ForEachPlayer { Custom(COPY_TARGETING_PLAYER_OR_PERMANENT) }` and `Custom(ORDER_COPIES_MADE)`, and the per-player custom effect called it.
- **The rule now:** one instruction's copies of one spell for one player are one copy event, however worded. `copy::additional_copies` only notes (spell, player) while a copy event is open; `copy::begin_copy_event` / `end_copy_event` open and close it, and `end_copy_event` makes the added copies once for each noted (spell, player). The state is `KeywordState::copy_event` (kw/keyword_state.rs), next to the registry hook (`additional_spell_copies`) that Twinning Staff implements.
- **Where it's opened:** `Effect::ForEach` whose body is a spell-copy instruction (resolve.rs; the same condition that already had it order all the copies with one question). Zevlor's custom pair adds the copies once, in `ORDER_COPIES_MADE` (kw/choices_5_filters.rs), before ordering all of them. No card name is special-cased.
- **Unchanged:** `CopySpell`/`CopySpellExcept` counts (storm, replicate, gravestorm, "copy it twice / X times"), casualty's copy, CR 707.10d copies, each player's own copies (Hive Mind, Curse of Echoes, Tempt with Mayhem, demonstrate), epic, Psychic Rebuttal, and copies of cards (Mizzix's Mastery, `CopyCard`, never affected).
- **The only copy-count replacement is Twinning Staff** (Oracle data searched for "that many times plus", "one or more times", "would copy", "instead copy", "additional copy" and "an additional time"). The nearest are Howl of the Horde's raid clause ("when you next cast an instant or sorcery spell this turn, copy that spell an additional time"), a second delayed trigger and so its own copy event, and the "triggers an additional time" statics (CR 603.2d), which copy nothing. "Copy it N times" was already one event in the engine (`Effect::CopySpell { count }` adds the copies once, after its N), and is unchanged.

**Readings tried.**
- **R1, one copy event (N + 1), now the engine's.** "For each of those creatures, copy that spell" is one instruction performed for all the creatures at once (608.2f); in that one happening the spell is copied N times, which is the event Twinning Staff's text looks for (700.1), and it modifies it once (614.5): N + 1, the additional copy going anywhere among the others (its ruling) with new targets allowed. Feather then counts like Zada, its functional twin, and like "copy it twice".
- **R2, one event per pass (2N), the engine's before.** Each pass of the "for each" copies the spell once ("copy that spell. The copy targets that creature."), so each is a copying that Twinning Staff turns into two. The tempting offer wording ("happens again for you a number of times", "repeat it") supports reading a "for each" instruction as repetitions. Against it: 608.2f's simultaneous processing, the Staff's "one or more times", and the count then depending on the wording (Feather 4, Zada 3 for the same two creatures).
- **R3, per copy (rejected).** The Staff adds a copy for each copy made: its own ruling gives one additional copy (per Staff) for "a spell ... being copied more than once".

**For the user.** With Twinning Staff ("If you would copy a spell one or more times, instead copy it that many times plus an additional time."), how many copies do "for each of those creatures, copy that spell" (Feather, Radiant Arbiter) and "for each other opponent, ..., copy that spell" (Zevlor, Elturel Exile) make when they copy the spell N times?
- **(1) N + 1, one copy event (now the engine's).** The "for each" instruction copies the spell N times in one happening (CR 608.2f); Twinning Staff, whose event is copying a spell "one or more times" (700.1), adds one copy to it (614.5), as it does to "copy it twice", storm and Zada's "copy that spell for each other creature". Feather's ruling describes its copies as Zada's does; rulings on Culmination of Studies and Tempting Contract treat other "for each" instructions as one event or as done at once; additive replacements apply once to an instruction that does something several times (Heron of Hope, Quantum Riddler) and to the counters several creatures' damage puts on a creature at once (Vizier of Remedies).
- **(2) 2N, one event per pass (the engine's before).** Each pass copies the spell once and gets its own additional copy; the tempting offer rulings' "the effect happens again for you a number of times" reads "for each" as repetition. The count then depends on the wording: Feather with two creatures 4, Zada with two creatures 3.

Recommendation: **(1)**. It is the reading under which every source fits without strain, it follows 608.2f's simultaneous processing and Twinning Staff's own "one or more times", and it makes the same copying give the same count whatever the wording. It is a judgment call: no source names the case, and a judge reading the "for each" as repetition would give 2N. Either way, the follow-up is small: keep or revert the copy event in `Effect::ForEach` and Zevlor's `ORDER_COPIES_MADE`, and update `copy-for-each-one-copy-event` and its tests.

**Readings re-assessed.**
- **R1 (one event) fits every source.** Its one contested step, that one "for each" instruction's copies are one happening, is what 608.2f's example, Suffer the Past, Wurmquake, Culmination of Studies, Tempting Contract and myriad say of their own "for each" instructions. Twinning Staff's "one or more times" then makes the happening one event (700.1) that it modifies once (614.5).
- **R2 (2N) needs a "for each" read as repetitions that are separate events.** The only words that sound like it are the tempting offer rulings' "happens again for you a number of times" (2013, before 608.2f; reused in 2024), whose structure Tempting Contract's ruling (2021) words "all at the same time", and Rottenmouth Viper's "the appropriate number of times", said of actions that "occur simultaneously". No source calls a pass its own event.
- **Why still D, not C:** none of these rulings is about copying or Twinning Staff. From "one event" for life, damage and tokens to "one copy event" is an analogy (700.1: "One “happening” may be treated as a single event by one ability and as multiple events by another."), and a judge could still read Feather's per-pass sentences ("copy that spell. The copy targets that creature.") as N copyings. So the entry stays provisional.

**For the user (skeptic).** The same question, and the same recommendation: **(1) N + 1**, one copy event, as the engine now plays it.
- With Twinning Staff, Feather's "for each of those creatures, copy that spell" and Zevlor's "for each other opponent, ..., copy that spell" copy the spell N times in one happening and get one additional copy per Staff, as "copy it twice", storm and Zada do. The CR's own "for each opponent, [action]" example (Blatant Thievery, 608.2f) is done at once, and every ruling found on a "for each" instruction treats it as one event (Suffer the Past: "a single life-gain event, not a number of separate ones"; Culmination of Studies) or as done at once (Wurmquake: "a number of tokens equal to the number of opponents ... at the same time"; Tempting Contract; myriad, in Zevlor's own release notes).
- Choosing (2) 2N instead means reading a "for each" as separate repetitions, on the strength of the tempting offer rulings' "the effect happens again for you a number of times" (2013), and giving Feather 4 copies where Zada, its functional twin, gets 3. The change back is small: drop the copy event in `Effect::ForEach` and Zevlor's `ORDER_COPIES_MADE`, and update `copy-for-each-one-copy-event` and its tests.
- Separately: the same "one instruction, one event" question is open for tokens, and there one ruling decides a card: Wurmquake's tokens should be one creation, and the engine makes them one at a time (engine-gaps G32).
