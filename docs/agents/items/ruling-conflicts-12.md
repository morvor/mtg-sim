# ruling-conflicts-12: "if it's the first time" rechecks, and the order of simultaneous "as enters" replacements

Run at effort max, with an independent investigator subagent and a separate adversarial skeptic subagent, as in ruling-conflicts-1. Judgment calls go in the register; anything the CR and rulings don't settle goes to the user with every source quoted verbatim with dates.

**Raised by:** rulings-residue-counters (landed e65bbb9f); see "Open questions the items found (for the coordinator)" in docs/agents/items/rulings-residue.md.

1. **"If it's the first time" on resolution.** The engine is inconsistent: Stalwart Successor (oracle/patterns/history_conditions_4.rs `first_time_counters`) and Vengevine check only when the ability triggers; Botanical Brawler (history_conditions.rs `nth_time_counters`) and Captain America, Living Legend (history_conditions_4.rs `first_time_referent`) re-count "== 1" on resolution, so with Cursed Wombat a granted trigger resolving first makes Brawler's do nothing. Quote CR 603.4 (intervening "if" clauses rechecked on resolution) in full and decide what "it's the first time ..." means when rechecked: the event that triggered it (still the first), or the state at resolution (a later event happened). Survey every "if it's the first time" / "for the first time" / "Nth time" wording and every ruling on them (dates), and the CR's word on trigger conditions that refer to the trigger event (603.4, 603.2, 700.14?). Make all patterns agree with the conclusion, with tests.
2. **Simultaneous "as enters" replacements.** "As enters" replacements of permanents entering at the same time are applied in move order (APNAP in Game::move_objects), not in an order the affected objects' controller chooses (CR 616.1; Thief of Blood ruling "you can apply ... any of them"). Check CR 614.12, 616.1 and the rulings (Thief of Blood, any others on simultaneous entering replacement order) and make the engine let the controller choose where it matters (default: move order), with tests on differing permanents.
