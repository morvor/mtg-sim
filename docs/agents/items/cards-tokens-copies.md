# cards-tokens-copies: Token and copy grammar: token creation modifiers, "become a copy ... except", copying cards/spells — 223 texts / 219 cards (186 unlocked alone)

SCOPE: 223 unsupported ability texts (223 on paper cards) blocking 219 paper cards; 186 of those become fully supported when this item alone is done (the others also have a text owned by another item). The full list, with the failing piece found by compiler probes, ships as items/cards-tokens-copies.texts.tsv (columns: cards blocked, normalized text, example card, piece kind, failing piece). Normalized text = reminder text removed, the card's own name as ~, numbers as N.

GOAL: Token creation with modifiers and recipients ("Create a tapped and attacking token that's a copy of that card, except it's a 3/3 black Wraith with menace", "Each player other than target player creates a 4/4 red Dragon", "You and that player each create three 1/1 white Spirit tokens", "create a red Aura enchantment token named Mark of the Rani attached to another target creature", "create a tapped Mutavault token", "If ~ was foretold, create X of those tokens instead"), copy effects with exceptions ("~ becomes a copy of target creature card exiled with it, except it's 4/4 and has this ability", "Target artifact you control becomes a copy of a second target artifact you control until end of turn, except it isn't legendary"), copying cards ("Copy those cards", "You may copy an instant or sorcery card in it"), token-qualified effects ("target creature token, player, or planeswalker", "sacrifice a token or a land").

PHRASE FAMILIES (texts in family; representative failing pieces and cards):
- token creation with modifiers ("create a tapped and attacking token that's a copy of that card, except ...", "for each opponent", "each player other than target player creates"): 128. e.g. "Create a N/N creature token of the chosen color and type." [Sarpadian Empires, Vol. VII]; "They create a Treasure token." [Vraska, the Cutting Glare]; "Create your choice of a Blood token, a Clue token, or a Food token." [Transmutation Font]
- "becomes a copy of ..., except ..." / "have ~ become a copy of ...": 24. e.g. "Enchanted creature is a copy of the chosen creature." [Metamorphic Alteration]; "Equipped creature is a copy of the last chosen card." [Paleontologist's Pick-Axe // Dinosaur Headdress]; "you may have ~ become a copy of that card, except its name is ~, it's legendary in addition to its other types, and it has hexproof and this ability." [Lazav, Dimir Mastermind]
- spell/card copies ("copy those cards", "you may copy an instant or sorcery card in it", "copy it except"): 42. e.g. "copy it." [Brass Knuckles]; "copy ~ twice." [Bygone Marvels]; "copy it for each kind of counter among permanents you control." [Storm of Forms]
- token-qualified effects ("target creature token, player, or planeswalker", "sacrifice a token or a land"): 22. e.g. "attach it to that token." [Ratonhnhaké꞉ton]; "put ~'s counters on that token." [Ambitious Augmenter]; "Incubate N five times, then transform all Incubator tokens you control." [Elesh Norn // The Argent Etchings]
- other (mixed; read the texts): 7. e.g. "• Incubate N twice." [Glissa, Herald of Predation]; "incubate N X times." [Progenitor Exarch]; "you may sacrifice a Food or pay {N}{W}." [Nimble Hobbit]

APPROACH: 1. Token description grammar (effects::parse_token_description) + modifiers (tapped, attacking, "that's blocking target creature", named, attached to, with counters) + recipients via player subjects (coordinate with cards-player-subjects) + counts (Value).
2. Copy grammar: "[a token that's | becomes] a copy of [object phrase], except [modification list]" → CreateTokenCopy/BecomeCopyExcept with Modification parsing shared with cards-characteristics (name, P/T, types, "has this ability", "isn't legendary").
3. Predefined tokens by name (Treasure/Clue/Food/Mutavault? — tokens_predefined.rs) and named legendary tokens ("create Smaug, a legendary 6/6 ...").

PARSER FILES INVOLVED: oracle/effects.rs (p_create_token, parse_token_description), patterns/r111_tokens.rs, tokens_copies_*.rs, r707_*.rs, copy_*.rs, replacements_tokens.rs, replacements_tokens_plus.rs, a701_create.rs

FILES THIS ITEM OWNS: new oracle/patterns/token_copy_grammar.rs; may edit r111_tokens.rs, tokens_copies_*.rs, r707_*.rs, copy_*.rs, replacements_tokens*.rs, a701_create.rs

ENGINE CAPABILITIES: CreateToken/CreateTokenCopy/CreateTokenAttached/BecomeCopyExcept exist; check token copies of cards in exile/graveyard (copiable values of a card, CR 707.2), tokens created for other players, "tapped Mutavault token" (token copy of a named card from CardDb).

BASELINE (`cargo run --release -q -p mtg-tools -- unsupported --limit 500 --filter "<s>"`; counts include other items' texts and digital-only cards): `token that's a copy of` → 110 texts / 111 cards; `becomes a copy of` → 36 texts / 36 cards; `except it` → 97 texts / 97 cards; `creates a` → 55 texts / 55 cards; `copy those cards` → 2 texts / 2 cards

COMMON RULES FOR CARD ITEMS:
- Generalize. Implement each construct as grammar (subject / verb / object phrase / qualifiers composed from phrases.rs, the value and condition parsers and the Builder's referent tracking), never one pattern per card wording; a fix should also cover wordings that aren't in the list. Unit-test the grammar on several real wordings.
- Faithfulness first. The parser must not accept text the engine doesn't implement exactly (an Oracle round-trip check audits every compiled card). For each family add TestGame tests with real cards that assert the in-game outcome (crates/mtg-engine/tests/cards/ or tests/cr/, citing cr!() for rules exercised and ruling!() for Scryfall rulings exercised).
- A text can contain a second failing construct owned by another item. Fix it when it is small; otherwise leave it and list it under remaining gaps with the owning item.
- One-offs. If a text's construct is genuinely unique (no other card shares it) and compiling it would be hacky, don't force it: once cards-manual-defs has landed, give it a hand-written definition in src/cards/ with a test; before that, list it as a manual candidate.
- Shared core files (oracle/effects.rs, phrases.rs, statics.rs, triggers.rs, costs.rs, ability.rs, eval.rs, resolve.rs) are edited by several items in parallel: keep edits there small (hooks, new enum variants handled everywhere), put grammar in this item's own pattern files, and merge origin often.
- Measure before and after: `cargo run --release -q -p mtg-tools -- card-coverage` and the baseline filters above. Report per family: texts fixed, texts remaining (each with a reason). Run `cargo run --release -p mtg-sim -- --random-decks --games 300` before finishing to catch panics in newly supported cards.
- DONE when about 90% or more of this item's texts compile with faithful, tested behaviour and every remaining text is listed with a reason (engine gap, belongs to item X, manual candidate).
