RULES NOTES:
- CR 601.3 (a spell can be cast only if a rule or effect allows it), 601.3b (as-though-flash permissions conditioned on qualities: the player may begin to cast it if choices made during the proposal could satisfy the condition), 601.2e (the proposed spell is checked once its choices are made: if they don't satisfy the condition the cast is illegal and is reversed, CR 733), 608.2g (casting during resolution ignores timing based on card type: Knowledge Pool ruling "Timing restrictions based on the card's type are ignored ... Other restrictions ... are not ignored").
- CR 400.7a (effects on a permanent spell continue to apply to the permanent it becomes), 400.7h (other parts of the effect that allowed a card to be cast can find the spell it became), 400.7i (the same for a land played).
- Alternative costs: CR 118.9, 118.9a (only one alternative cost; "without paying its mana cost" is one: Weftwalking ruling: additional costs may still be paid and mandatory ones must be), 107.3 (X is 0 when cast without paying its mana cost: Knowledge Pool ruling).
- Keyword costs granted: CR 702.119a (emerge), 702.94a (miracle), 702.143a (foretell), 702.85a/c (cascade; several instances trigger separately). Herigast rulings: once you begin casting with an emerge granted by Herigast, losing Herigast doesn't stop it; the sacrificed creature is still on the battlefield while the cost is determined.
- Spending: CR 609.4b ("as though it were mana of any [type]" changes only how a cost may be paid; the mana is still what it is: Celestial Dawn ruling "if the spell or ability checks the actual color of the mana, it can tell the difference"), 106.3 (mana's source).
- Adventures: CR 715.3, 715.3a (cast as an Adventure: only the alternative characteristics are evaluated).
- Linked exile per player: CR 607.2a; Uba Mask rulings: "You can't play cards you exiled with Uba Mask on previous turns", and cards you don't play stay exiled. Omen Machine rulings: the cast isn't optional; if it can't be cast (no legal targets), the card stays in exile.
- Look permissions: CR 708.5 (normally you may look only at face-down permanents and spells you control), 406.3.

COMMON RULES FOR CARD ITEMS (round 2):
- Generalize. Implement each construct as grammar (subject / verb / object phrase / qualifiers composed from phrases.rs, the value and condition parsers and the Builder's referent tracking), never one pattern per card wording; a fix should also cover wordings that aren't in the list. Unit-test the grammar on several real wordings.
- Faithfulness first. The parser must not accept text the engine doesn't implement exactly (the Oracle round-trip check audits every compiled card). For each family add TestGame tests with real cards that assert the in-game outcome (crates/mtg-engine/tests/cards/ or tests/cr/, citing cr!() for rules exercised and ruling!() for Scryfall rulings exercised).
- Texts marked "also needs <round-1 item>" belong to a round-1 item that is still in progress for one construct and to this item for the other. Do your construct; if that item has landed when you finish, make the whole text work, otherwise list the text as waiting for it. A text can also contain a second construct that the probes didn't reach: fix it when it is small, otherwise list it with the item that owns that area.
- One-offs. The hand-written mechanism exists (src/cards/, `ManualAbility`, `mtg-tools manual-check`; policy in src/cards/mod.rs). If a text here turns out to be a genuine one-off (no other card shares the construct), don't force a pattern: list it in your report for cards-manual-defs-2. Never hand-write a construct that two or more cards share.
- Shared core files (oracle/effects.rs, phrases.rs, statics.rs, triggers.rs, costs.rs, ability.rs, eval.rs, resolve.rs) are edited by several items in parallel: keep edits there small (hooks, new enum variants handled everywhere), put grammar in this item's own pattern files, and merge origin often.
- Build hygiene (CLAUDE.md): `export CARGO_BUILD_JOBS=2`, one cargo build at a time per worktree, no second checkout for before/after numbers.
- Measure before and after: `cargo run --release -q -p mtg-tools -- card-coverage`, the baseline filters (`cargo run --release -q -p mtg-tools -- unsupported --limit 500 --filter "<s>"`) and `mtg-tools unsupported --card "<Name>"` for the listed cards. Report per family: texts fixed, texts remaining (each with a reason). Run `cargo run --release -p mtg-sim -- --random-decks --games 300` before finishing to catch panics in newly supported cards.
- DONE when about 90% or more of this item's texts compile with faithful, tested behaviour (TestGame tests per family with real cards; for riders, check that casting the same card another way doesn't get the rider) and every remaining text is listed with a reason (engine gap, belongs to item X, manual candidate).
