# cards-history-conditions: Condition grammar II: game-history conditions ("if you've cast/attacked/sacrificed ... this turn", "if a creature died this turn", mana spent, cast status) — 326 texts / 328 cards (285 unlocked alone)

SCOPE: 326 unsupported ability texts (326 on paper cards) blocking 328 paper cards; 285 of those become fully supported when this item alone is done (the others also have a text owned by another item). The full list, with the failing piece found by compiler probes, ships as items/cards-history-conditions.texts.tsv (columns: cards blocked, normalized text, example card, piece kind, failing piece). Normalized text = reminder text removed, the card's own name as ~, numbers as N.

GOAL: Compile history conditions compositionally as queries over recorded game events: [actor] [verb past] [object phrase] [zone/qualifiers] [this turn | this combat | since your last turn | this game] [N or more times / total power N or greater]. Examples: "if you cycled two or more cards this turn", "if a creature card left your graveyard this turn", "if another Human died under your control this turn", "if you haven't cast a spell from your hand this turn", "if an opponent lost 2 or more life this turn", "if at least four mana was spent to cast it", "if mana from a Treasure was spent to cast it", "if it's the second creature spell you cast this turn", "if this ability has been activated four or more times this turn", "if you attacked with creatures with total power 6 or greater this combat".

PHRASE FAMILIES (texts in family; representative failing pieces and cards):

- "if a/an [filter] [died/entered/left/was put into a graveyard] this turn": 64. e.g. "if Kaito entered this turn" [Kaito Shizuki]; "if no creatures died this turn" [Titan Hunter]; "If excess damage was dealt to that creature this way, investigate." [Torch the Witness]

- other (mixed; read the texts): 46. e.g. "If you controlled that permanent, draw a card." [Geistwave]; "if ~ attacked this combat" [Tolsimir, Midnight's Light]; "~ doesn't untap during your untap step if it attacked during your last turn." [Goblin Rock Sled]

APPROACH: 1. Introduce (or extend) one event-query AST rather than one Condition/Value variant per phrase: e.g. `HistoryQuery { event: EventKind (cast, died, entered, left zone, put into graveyard, sacrificed, discarded, drew, cycled, gained/lost life, dealt/was dealt damage, attacked, blocked, activated, played land, created token, put counters, searched, committed crime ...), actor: PlayerFilter, object: Filter, zones, window: ThisTurn | ThisCombat | LastTurn | ThisGame | SinceYourLastTurn }` with `Condition::Happened(q, Cmp, n)` and `Value::CountEvents(q)` (cards-values-results uses the same Value for "the number of creatures that died this turn"). Evaluate over `Game::turn_events` / `TurnHistory` (game.rs) — fold the existing special variants (CreaturesDiedThisTurn, SpellsCastThisTurn, PermanentsEnteredThisTurn, custom "you_lost_life_last_turn" ...) into it where cheap.
2. Grammar: a history clause parser in a pattern file: subject (you / an opponent / a player / a creature / [object phrase]) + verb in past/perfect tense ("cast", "have cast", "'ve cast", "haven't", "didn't", "died", "was put into a graveyard from the battlefield") + object phrase (reuse phrases::parse_object_phrase) + time window, with negation and counts ("two or more", "N or more ... total").
3. Cast-status and payment conditions: "if it was cast", "if you cast it from your hand", "if ~ was kicked/bargained/foretold", "if {B}{B} / at least three green mana / mana from a Treasure was spent to cast it" — CastInfo already records cost choices and spent mana (Value::ManaSpent, ColorsSpent); extend to mana sources (Treasure, creature, Cave) and amounts by color.
4. Ordinals: "the first/second ... each turn", "if it's the first combat phase of the turn", "if this is the third time this ability has resolved this turn" (TimesResolvedThisTurn exists).

PARSER FILES INVOLVED: oracle/statics.rs (parse_condition), patterns/entered_this_turn.rs, patterns/spells_cast_this_turn.rs, patterns/opponent_this_turn.rs, patterns/r120_dealt_damage_this_turn.rs, patterns/alternative_cost_paid.rs, patterns/mana_spent_symbols.rs, patterns/once_each_turn_cast.rs, patterns/statics_conditions.rs

ENGINE CAPABILITIES: MISSING: a game-long history ("this game": "you've cast another spell named ~ this game", "the Ring has tempted you two or more times this game", "times it's been cast from the command zone this game") — TurnHistory/turn_events only cover the current and last turn; add a compact game log of the queried event kinds. Several per-turn facts are not recorded yet (cards cycled, cards discarded per player, cards that left a graveyard, counters put by player, cards exiled this turn, abilities activated per source count beyond `activated`, total power of attackers this combat, mana source kinds spent). Record them generically from events, not per card.

BASELINE (`cargo run --release -q -p mtg-tools -- unsupported --limit 500 --filter "<s>"`; counts include other items' texts and digital-only cards): `this turn` → 1165 texts / 1185 cards; `you've cast` → 50 texts / 53 cards; `died this turn` → 34 texts / 34 cards; `was spent to cast` → 57 texts / 59 cards; `if you attacked` → 19 texts / 19 cards; `if it was cast` → 3 texts / 3 cards; `this game` → 19 texts / 19 cards

COMMON RULES FOR CARD ITEMS:
- Generalize. Implement each construct as grammar (subject / verb / object phrase / qualifiers composed from phrases.rs, the value and condition parsers and the Builder's referent tracking), never one pattern per card wording; a fix should also cover wordings that aren't in the list. Unit-test the grammar on several real wordings.
- Faithfulness first. The parser must not accept text the engine doesn't implement exactly (an Oracle round-trip check audits every compiled card). For each family add TestGame tests with real cards that assert the in-game outcome (crates/mtg-engine/tests/cards/ or tests/cr/, citing cr!() for rules exercised and ruling!() for Scryfall rulings exercised).
- A text can contain a second failing construct owned by another item. Fix it when it is small; otherwise leave it and list it under remaining gaps with the owning item.
- One-offs. If a text's construct is genuinely unique (no other card shares it) and compiling it would be hacky, don't force it: once cards-manual-defs has landed, give it a hand-written definition in src/cards/ with a test; before that, list it as a manual candidate.
- Shared core files (oracle/effects.rs, phrases.rs, statics.rs, triggers.rs, costs.rs, ability.rs, eval.rs, resolve.rs) are edited by several items in parallel: keep edits there small (hooks, new enum variants handled everywhere), put grammar in this item's own pattern files, and merge origin often.
- Measure before and after: `cargo run --release -q -p mtg-tools -- card-coverage` and the baseline filters above. Report per family: texts fixed, texts remaining (each with a reason). Run `cargo run --release -p mtg-sim -- --random-decks --games 300` before finishing to catch panics in newly supported cards.
- DONE when about 90% or more of this item's texts compile with faithful, tested behaviour and every remaining text is listed with a reason (engine gap, belongs to item X, manual candidate).
