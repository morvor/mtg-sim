## Exemptions

- **100.6b**: Informational: where to find tournaments (the Store & Event Locator website). No game behavior.
- **100.7**: Informational: some casual/un-set cards (playtest, silver-bordered, acorn) have features outside the Comprehensive Rules. It states no rule the engine could apply; those cards simply aren't modeled beyond their oracle text.
- **106.4a**: Announcing the mana left in a pool after paying a cost is a communication procedure between players; the engine keeps every mana pool as public game state (Player::mana_pool), so there is nothing to execute.
- **106.4b**: Announcing unspent mana when passing priority is a communication procedure between players; the engine keeps every mana pool as public game state (Player::mana_pool), so there is nothing to execute.
- **107.10**: The Future Sight type icon is a printed frame marker that "has no effect on game play"; card types come from the type line, so there is no engine behavior to test.
- **107.9**: The tombstone icon is a printed frame marker that "has no effect on game play"; card data carries no such characteristic and nothing in the engine can observe it.
- **108.6**: Purely a cross-reference ("For more information about cards, see section 2"); it states no rule of its own.
- **201.1**: Where the name is printed on the physical card (its upper left corner) is card layout; the engine takes each card's name from the Oracle card reference, so there is nothing to execute. Names themselves are tested under 201.2-201.6.
- **201.3c**: Describes the interchangeable names indicator printed on later printings (bottom left corner); printing information not in the card data. Interchangeable names are tested under 201.3, 201.3a, 201.3b and 201.4g.
- **206.1**: The expansion symbol identifies the set of a printing and "has no effect on game play"; it isn't a characteristic and the engine's Oracle card data has none. Rules about names originally printed in a set are tested under 206.3.
- **206.2**: The color of the expansion symbol indicates the printing's rarity; printed information with no effect on game play.
- **206.5**: Points to the Card Set Archive on the Magic website; states no game rule.
- **207.3**: Decorative icons in the background of the text box (guild and faction icons) "have no effect on game play" and aren't part of the card data.
- **213.1**: Information printed below the text box "has no effect on game play"; it's printing information, not part of the Oracle card data the engine uses.
- **213.1a**: Collector numbers are printing information with no effect on game play.
- **213.1b**: The rarity letter after the collector number is printing information with no effect on game play.
- **213.1c**: Promotional information on promotional printings has no effect on game play.
- **213.1d**: The version information on printings with interchangeable names is printing information; interchangeable names themselves are tested under 201.3.
- **213.1e**: The set and language codes (and the premium star) are printing information with no effect on game play.
- **213.1f**: The illustration credit is printing information with no effect on game play.
- **213.1g**: The legal text (trademark and copyright) is printing information with no effect on game play.
- **309.4b**: Room names are flavor text with no effect on game play; there is no behavior to exercise (the room abilities themselves are tested under 309.4c).

- **406.8**: Informational: historical terminology ("removed from the game", "set aside") replaced by Oracle errata; the engine reads Oracle text, which says "exile", so there is no game behavior to test
